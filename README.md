# RoughGorge

RoughGorge is a Cloud-native, Distributed Data Pipeline Engine utilizing data-parallel processing and auto-scaling for optimized big data analytics.

RoughGorge is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughGorge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
